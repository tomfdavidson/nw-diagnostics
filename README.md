# Diagnostic waiting times dashboard (DM01)

An interactive view of NHS England's monthly diagnostics waiting times and activity data (DM01), by region, provider, provider type and test. It opens on the North West, non-obstetric ultrasound, latest month.

Open the dashboard from this repository's GitHub Pages link (Settings > Pages).

## Source

NHS England, [Monthly Diagnostics Waiting Times and Activity](https://www.england.nhs.uk/statistics/statistical-work-areas/diagnostics-waiting-times-and-activity/monthly-diagnostics-waiting-times-and-activity/), provider-level "Provider by Test" files, April 2024 onwards. Updated monthly after NHS England publishes.
